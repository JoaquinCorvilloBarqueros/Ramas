git init - Inicializa un repositorio nuevo en el directorio actual

git status - Muestra el estado del proyecto

git add - Añade archivos al area de preparacion

git commit - Crea un commit con los cambios añadidos en la preparacion

git branch - Lista o crea ramas

git checkout - Cambia a otra rama

git merge - Fusiona otra rama con la actual

git push - Sube los commits locales al repositorio remoto

git log - Muestra el historial de commits en forma de grafo
